How It Works

Powered by state-of-the-art vision-language models

🧠
Vision Transformer (ViT)
Google's ViT-Base splits your image into 16×16 patches and encodes them as rich visual tokens that capture spatial relationships and fine details.
✍️
GPT-2 Decoder
OpenAI's GPT-2 language model decodes the visual tokens into fluent natural language using beam search for high-quality caption generation.
🎨
Style Enhancement
A post-processing layer transforms the base caption into Short, Balanced, or Detailed formats using keyword analysis and template expansion.
